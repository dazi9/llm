# 第十章 十个练习与下一步

> 十个由浅入深的练习(每个都锚定在本项目的真实代码上),
> 然后诚实地回答那个必然会问的问题:**然后呢?**

## 10.1 十个练习(每题标注:用到的章 + 预期工作量)

**练习 1(热身,1h | ch02)**:给 `train_bpe` 实现 CS336 规范的
字典序 tie-breaking(`src/tokenizer.py:71` 附近,频次并列时取
字典序更大的 pair)。用 TinyStories 重训 10K 词表,
对比两种 tie-breaking 的分词差异——预期差异极小,
这个"预期落空"本身就是数据点。

**练习 2(1-2h | ch03)**:把 `naive_attention`(`src/model.py:126`)
扩展为支持 **GQA 的 naive 版本**(对 repeat_interleave 后的 k,v)。
验收:与 sdpa 在 gqa2 配置下逐位对拍(参考 test_flash.py 的容差)。

**练习 3(2h | ch04)**:实现 **interleaved 风格的 RoPE** 作为
`RotaryPositionalEmbedding` 的可选模式,并用 test_rope_reference_match
的思路写一个"两种约定在相对距离上等价"的验证——
它们绝对位置输出不同,但 q·k 点积应只依赖相对位置。

**练习 4(2h | ch05)**:给训练循环加 **梯度累积**
(`src/train.py:155` 的 accum 循环已存在,但把它做成
`--accum` 之外还能自动从 batch 对齐),用 batch 8 + accum 4 复现
batch 32 的训练曲线——验证"有效 batch 相同则曲线重合"。

**练习 5(2-3h | ch06)**:把 `get_vocab_base_pre` 的补丁
(ch09 的 `gpt-2` hack)做成**正式的 pretokenizer 注册**:
让 `make_tokenizer_json.py` 生成 llama.cpp 新版认识的元数据,
提交 upstream——这可能是你第一个被合并进开源项目的 patch。

**练习 6(2-3h | ch06)**:实现 **fused 交叉熵**:把 CE 的
log-sum-exp 融合成一个 Triton kernel(模仿 flash_attention.py
的结构),用 benchmark_adamw.py 的方法测量对训练步时间的贡献。

**练习 7(半天 | ch02+ch07)**:**数据配比实验**:把 TinyStories
和 Fineweb 的 token bin 按比例混合(0/50/100%、25/75%),
各训一个小模型,用"故事流畅度(人评)"和"事实密度(关键词命中率)"
画一张帕累托图。这是本项目最有潜力的一篇内容。

**练习 8(半天 | ch08)**:把消融扩展到 **多 seed**:挑 qk_norm 和
baseline,各跑 3 个 seed,报均值±标准差——亲手体会
"单 seed 的 0.03 差异"有多少是真信号。改 `run_ablation.py`
加 `--seeds` 参数,验收标准是汇总脚本支持聚合。

**练习 9(半天 | ch09)**:**4-bit 之外**:给导出链加 Q8_0 和
Q6_K 两种量化,各生成 50 个样本,设计一个(粗略但诚实的)
质量对比协议——体感量化损失到底是多少。

**练习 10(1-2 天 | 全书)**:**从零写一个 2 层玩具模型**,
只用本书教过的组件(BPE、注意力、RMSNorm、RoPE、SwiGLU、AdamW),
不参考 src/(合上书写),然后让它过全部 23 个测试里的架构部分。
写对了,你就真的会了;写错了,你会精确知道自己哪一章没懂。

## 10.2 三个不需要大算力的研究方向

练习之上,是研究方向。以你的硬件(单卡 12GB)和已有的 harness,
这三条线的门槛都已经探过底:

**方向一:数据配比的帕累托前沿(练习 7 的完全体)**。
文献里"数据混合决定能力"的系统性小规模研究意外地少。
你的两套语料、消融 harness、评测口径全部现成——差的是
混合比例扫描(5-6 个点)和一份严谨的评测协议。
定位:workshop / arXiv note / 高质量技术博客。

**方向二:文本架构结论在语音 LM 上的迁移**(Interspeech 2027,
截稿 2027-02-09)。用预训练 HuBERT 的离散 token 替换文字 token,
QK-Norm/GQA/NoPE 的消融原题重做,用预训练 ASR 的 WER 当指标。
"文本结论是否迁移到语音"这个问题本身就有出版价值,
而你的 harness 是现成的——只需要把数据管线换成语音 token 化。

**方向三:小模型可解释性**。你拥有一个**自己从零训的、每个参数
来历都清楚的 134M 模型**——这是可解释性研究的完美标本:
注意力头在干什么(第三章)、QK-Norm 改变了什么(消融的机理)、
loss 2.68 的模型"知道"哪些事实。探针和 SAE 都是小算力工具。

## 10.3 硬件的诚实边界

| 想做的事 | 你的笔记本 | 需要 |
|---|---|---|
| 100-300M 全参训练 | ✅ 一夜-三夜 | 现状即可 |
| 1B 全参预训练 | ❌ | 租 4090 ×4(¥10/时级) |
| 7B QLoRA 微调 | ⚠️ 12GB 边缘可行 | 现状即可,慢 |
| 7B 全参微调 | ❌ | A100 ×2 起 |
| 7B 推理(Q4) | ✅ | 现状即可 |

结论:**训练和实验,这台机器还有很长的路;只有"更大规模"这一个
方向需要新的硬件,而那之前有大量免费的研究空间。**

## 10.4 这本书没讲的事

诚实清单(也是下一条路):注意力变体(Mamba/SSM 的线性注意力)、
MoE(专家混合)、RLHF/DPO(对齐)、多模态、以及一切与"更大"有关的东西。
这些方向的入门书单和算力门槛,与本书的关系是:**本书教你的
"受控实验 + 诚实统计 + 工程落地"方法学,是它们共同的门票。**

## 10.6 结语

xv6 的前言里有一句话,本项目借来作结:

> *Claritas est distinctio* —— 清晰,源于区分。

134M 模型不能通过图灵测试,但它把"语言模型"从一句营销词
区分成了 12 层可验证的机械结构。你亲手搭完了它、训练了它、
优化了它、打包了它——**你现在知道的不是"AI 是什么",
而是"AI 是怎么被制造的"。** 下一步,无论去哪个方向,
都从这里出发。
