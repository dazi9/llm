# 第一章 从字符预测说起:语言模型到底是什么

> 本章不写一行数学。读完你将理解:语言模型在做什么、它为什么会"看起来聪明"、
> 以及为什么"预测下一个字"这件无聊的小事,能堆出一台会写作的机器。
> 你还将亲手运行本项目 trained 出来的模型,并让它在你的电脑上写一段话。

## 1.1 一个你已经玩了一辈子的游戏

这个游戏叫**文字接龙**:我说"今天天气真",你接"好"。
你几乎不假思索——但请慢下来,想想刚才发生了什么:

1. 你读到了一段上文:"今天天气真"
2. 你在几万个候选字里,几乎瞬间排除了所有不合理项
3. 你选中了一个使句子最通顺的字

**语言模型(language model, LM)就是一个把这个游戏玩到极致的程序**:
给它任意长的一段文字,它输出"下一个字符(或词)应该是什么"的概率分布。
仅此而已。没有理解,没有意图,没有对话——只有接龙。

## 1.2 为什么"无聊的接龙"会显得聪明

直觉上,接龙和"智能"应该毫不相干。但 2017 年之后整个行业发现了一件事:

> **把接龙玩得足够好,智能的样子会自己浮现。**

想一想,要接好下面这句,你需要什么:

> "水的化学式是 H₂"

你需要在某个时刻"读过"化学常识、记住它、并且在合适的语境里把它调出来。
预测下一个字,逼着模型把**语言中蕴含的规律**——包括事实、逻辑、风格——
全部压进自己的参数里。这个"逼"的过程,就叫**训练**。

当然,"显得聪明"和"真的聪明"之间有巨大的鸿沟。第二章之后你会看到,
这个鸿沟在 1 亿参数的尺度上表现为:能写出流畅的段落,但会一本正经地编造事实。
这不是缺陷修复一下就好了——这是这个尺度的物理极限,也是本项目诚实的地方。

## 1.3 一个思想实验:如果只会查表

假设我们造一个"查表接龙器":统计一份语料里每个三字组合后面接什么字,
做成一张巨大的表。它能接龙,但有致命弱点:

- 语料里没出现过的上文,它就哑了
- 表的大小随上文长度**指数爆炸**
- 相似但不相同的上文,学到的经验无法互相借用

突破口在 1943 年就有了雏形,2017 年(GPT 所用的 Transformer 架构发表)彻底成熟:
**不要查表,用一个可学习的函数来猜**。给函数输入上文,输出对每个候选字的打分;
猜错了就微调函数的几百万个参数。这个函数就是**神经网络**,
而本项目 `src/model.py` 里的 134M 个参数,就是这台函数机器的全部零件。

## 1.4 你的第一个模型有多大、见过什么

本项目最终训练出的模型 v2:

| 属性 | 数值 | 直觉换算 |
|---|---|---|
| 参数量 | 134,107,392 | 1.34 亿个可调旋钮;GPT-4 约为它的 10000 倍 |
| 词表 | 32,000 | 它认识 3.2 万个"字块"(token),中文它几乎不认识 |
| 训练数据 | Fineweb-Edu 9.83 亿 token | 约 7 亿次"接龙练习" |
| 训练时长 | 7.9 小时 | 在你同款笔记本显卡上 |

注意最后一行:**这不是某个大厂的遥不可及造物,是你笔记本一个通宵的产出**。
这也是本书与 xv6 一样的立场——所有部件小到可以被一个人完整理解。

## 1.5 训练在做什么:让猜错的代价下降

训练循环(第五章细讲)每一轮只做三件事:

1. 从数据里取一段文字,遮住最后一个词,让模型猜
2. 用一个函数(loss)衡量"猜得多差"
3. 沿着"让 loss 变小"的方向,微调所有参数一小步

重复十亿次,loss 从 10.5(纯瞎猜,32K 选 1 的自然对数)降到 2.68
(等效于平均每 15 个候选里猜 1 个)。曲线长这样(摘自本项目真实日志):

```
step 15000  val_loss 3.13   ← 还在胡言乱语
step 50000  val_loss 2.86   ← 开始像人话
step 90000  val_loss 2.68   ← 语法完全正确,开始"懂"领域词汇
step 120000 val_loss 2.68   ← 收益放缓,收工
```

**读懂这条曲线,你就读懂了整个深度学习的日常。** 剩下的章节只是在解释
"这条曲线为什么能降下来"。

## 1.6 自己动手:让模型给你写一段话

前置:GETTING_STARTED.md 的第 0-4 步已完成(有一个训练好的模型)。

```bash
cd ~/llm-lab/code
python src/sample.py --ckpt ~/llm-lab/runs/v2/model_final.pt \
    --prompt "The history of artificial intelligence" --max-new 150
```

**预期输出**:几段英文,第一句接得上你的开头,中间会出现流畅但可疑的事实
(我们看过它"发明"历史)。把 `--temperature` 改成 1.3 再跑一次——
你会得到一段更加天马行空的文字。这个参数控制的是"每次接龙时有多冒险",
第六章会讲它为什么有效。
